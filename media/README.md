# Video

Drop the barn footage here as `hero.mp4` (H.264, muted, ~8–15s loop, 1920×1080).
Both `index.html` and `landing-c.html` reference `media/hero.mp4` already — no
code change needed once the file exists. Until then the poster image carries it.

Guidance for the shoot: slow movement only (a horse being led down the aisle,
hands tacking up, light through a doorway). Avoid fast cuts and anything that
pulls the eye off the headline. Keep a clear, calm area on the left third of
frame where the type sits.
